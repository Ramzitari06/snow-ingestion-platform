# Snow Ingestion Platform

Squelette du projet de plateforme d'ingestion de donnees.

## Structure

- `app/` : API, services, connecteurs, modeles et point d'entree.
- `data/raw/` : fichiers sources a ingerer.
- `data/processed/` : donnees traitees.
- `data/archive/` : donnees archivees.
- `sql/ddl/` et `sql/dml/` : scripts SQL de definition et de manipulation.
- `tests/` : tests du projet.
- `dbt/`, `docker/` et `terraform/` : repertoires reserves aux configurations correspondantes.

Les fichiers dans `data/raw/` sont des emplacements de depart a remplacer par les donnees reelles.
